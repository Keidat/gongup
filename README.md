## GitHub Pages

이 폴더의 index.html, style.css, app.js, data.js, written.js, notes.md, .nojekyll을 저장소 최상위에 올립니다. Settings → Pages → Deploy from a branch → main / root를 선택합니다. .openai나 다른 사이트의 설정 파일은 필요하지 않습니다.

별도 설치나 빌드가 필요 없습니다. 학습 기록은 해당 브라우저에 저장됩니다. notes.md는 페이지별 원본 요약입니다.
